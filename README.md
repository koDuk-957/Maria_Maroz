# Мария Мароз — электронная визитка

Самостоятельный сайт-визитка. Для открытия страницы не нужны Telegram-бот, команды или Telegram Mini App: достаточно обычной ссылки.

## Локальный запуск

Требуется Python 3.12.10.

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Запустите сайт:

   ```bash
   python main.py
   ```

3. Откройте http://localhost:10000

## Развёртывание на Render

Используйте существующий **Web Service**:

- Build Command: `pip install -r requirements.txt`
- Start Command: `python main.py`
- Instance Type: `Free`

Переменные `BOT_TOKEN`, `CONTACT_USERNAME` и `MINIAPP_URL` больше не нужны. Сайт не подключается к Telegram API и не регистрирует webhook.

## Адреса

- Основная электронная визитка: https://maria-maroz.onrender.com/
- Старый адрес /miniapp перенаправляет на основную визитку.
- Проверка доступности: https://maria-maroz.onrender.com/health

Ссылку на основную страницу можно отправлять в Telegram, MAX, SMS или открывать в обычном браузере. Встроенный просмотр зависит от приложения; если оно не показывает страницу внутри себя, ссылка откроется во внешнем браузере.

Бесплатный Render Web Service может засыпать после периода без запросов. Поэтому первый переход после простоя иногда занимает больше времени. Для полностью статического сайта без такого засыпания можно отдельно перевести публикацию на бесплатный Static Site.

## Структура

- `main.py` — лёгкий веб-сервер для визитки.
- `index.html` — основная электронная визитка.
- `miniapp.html` — сохранённый прежний файл Mini App; больше не используется сайтом.
- Файлы Telegram-бота оставлены в репозитории как архив проекта, но приложение их не запускает.
